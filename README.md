# Students-grades-accounting
Учебное задание по реализации системы учета студентов и их оценок.

## Задание
Реализовать небольшую систему учёта студентов и их оценок. В PHP console. 
## Классы
### Класс Student
#### поля: firstName, lastName, grades (массив чисел).
#### методы:
- addGrade(grade) — добавить оценку.
- getAverage() — вернуть средний балл.
### Класс Group
#### поля: 
- groupName
- students (массив объектов Student).
#### методы:
- addStudent(student) — добавить студента в группу.
- getGroupAverage() — вернуть средний балл по всей группе.
- getBestStudent() — вернуть студента с наибольшим средним баллом.
## Функции вне классов:
- printStudentInfo(student) — вывести имя, фамилию и средний балл студента.
- printGroupInfo(group) — вывести название группы, количество студентов, общий средний балл.


## Пример использования:
1. Создать 2–3 студентов, добавить им оценки.
2. Добавить студентов в группу.
3. Вывести информацию о каждом студенте и о группе.
4. Показать лучшего студента.
